# Codes d'erreur Colissimo

Quand Colissimo refuse une étiquette, un test de connexion, un bordereau ou une recherche de points relais, myColis traduit sa réponse en un message qui dit quoi corriger. Cette page liste ces messages par code, regroupés par sujet.

## Où voir le code

Dans l'action **Créer l'étiquette (myColis)** et dans le rapport de la génération groupée, le code de Colissimo suit le message entre parenthèses, par exemple « … Corrigez l'adresse de livraison de la commande dans Shopify. (30211) ». Cherchez ce code dans les tableaux ci-dessous. Un message sans code vient de myColis lui-même, qui a repéré le problème avant d'interroger Colissimo : il est décrit dans [Dépannage](/docs/depannage).

Dans les tableaux, « … » remplace une valeur propre à l'envoi, comme un nom de produit ou un détail donné par Colissimo.

## Identifiants et compte

Ces erreurs empêchent toute étiquette. Vérifiez votre n° client et votre clé API dans la section **Connexion Colissimo** des réglages, puis relancez le test de connexion.

| Code | Message |
|---|---|
| 30000 | Le n° client et la clé API (ou le mot de passe) ne correspondent à aucun compte Colissimo. Vérifiez-les ; la clé API se génère dans Colissimo Box, rubrique Mon profil. |
| 30001 | Le n° de compte transmis à Colissimo est incorrect. Vérifiez votre n° client. |
| 30007 | Votre compte Colissimo est inactif. Contactez votre interlocuteur commercial Colissimo. |
| 30008 | Ce service n'est pas autorisé pour vos identifiants. Contactez votre interlocuteur commercial Colissimo pour réinitialiser votre compte client. |
| 30013 | Trop de tentatives avec des identifiants incorrects : Colissimo bloque temporairement l'authentification. Patientez quelques minutes, vérifiez vos identifiants puis réessayez. |

| Code | Message |
|---|---|

| 30014 | Colissimo n'a pas reçu le code produit. Contactez le support myColis. |
| 30015 | Code produit refusé par Colissimo. Vérifiez les produits inclus dans votre contrat. |
| 30700 | Ce produit ne figure pas dans votre contrat Colissimo. Vérifiez les produits inclus avec votre interlocuteur commercial. |
| 30025 | Colissimo n'a pas reçu le format d'étiquette. Choisissez un format dans les réglages. |
| 30026 | Format d'étiquette refusé par Colissimo. Choisissez un autre format dans les réglages. |

## Messages sans code

Ces messages ne correspondent pas à un code de Colissimo, mais à une réponse absente, illisible ou inattendue.

| Situation | Message |
|---|---|
| Clé refusée sans autre précision | La clé API est invalide, ou le compte Colissimo est inactif ou résilié. Vérifiez vos identifiants. |
| Colissimo ne répond pas à temps | Colissimo n'a pas répondu à temps. Réessayez dans quelques minutes. |
| Colissimo injoignable | Impossible de joindre Colissimo. Réessayez dans quelques minutes. |
| Service momentanément indisponible | Colissimo est indisponible pour le moment (HTTP …). Réessayez dans quelques minutes. |
| Réponse inexploitable | Réponse de Colissimo illisible. Réessayez ; si le problème persiste, contactez le support myColis. |
| Requête refusée par Colissimo | Colissimo a refusé le format de la requête. Contactez le support myColis. |
| Code non répertorié par myColis | Code Colissimo … : … |
| Code de recherche de points relais non répertorié | Recherche de points relais refusée par Colissimo (code … : …). Contactez le support myColis si le problème persiste. |

Pour un code non répertorié, le message reprend le code et le texte de Colissimo tels quels. Si vous ne voyez pas quoi corriger, écrivez au support myColis à [support@webesencia.com](mailto:support@webesencia.com), en indiquant le code et le n° de commande.
