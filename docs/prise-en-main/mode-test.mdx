# Mode test

Le mode test vous laisse essayer tout le parcours de myColis sans créer une seule étiquette chez Colissimo, même sans contrat. Cette page explique ce qu'il change, ce qu'il ne change pas, et comment passer aux vraies étiquettes.

## Activer le mode test

1. Ouvrez myColis, puis **Réglages**.
2. Activez l'interrupteur **Mode test** dans la section **Connexion Colissimo**.

Le réglage est enregistré dès le basculement, sans autre bouton, et un message confirme **Mode test activé**. Le n° client et la clé API deviennent facultatifs : vous pouvez laisser les champs vides.

## Ce que fait le mode test

Tant qu'il est actif, la section affiche ce bandeau : « Mode test activé : myColis génère des étiquettes d'exemple marquées DEMO, avec un numéro fictif, sans jamais créer d'étiquette chez Colissimo. Sur une boutique de développement, la commande est marquée comme expédiée sans notifier le client ; sur une boutique réelle, elle n'est pas modifiée. Aucun identifiant Colissimo n'est nécessaire en mode test. »

L'étiquette d'exemple a le format choisi dans vos réglages, PDF ou ZPL, et porte la mention « ÉTIQUETTE D'EXEMPLE : DEMO ». Elle n'est pas valable pour un envoi : ne la collez jamais sur un colis. Un envoi qui demande une déclaration douanière reçoit aussi une CN23 d'exemple, marquée DEMO de la même façon.

Sur une boutique de développement, la commande est marquée comme expédiée avec le numéro fictif, sans que Shopify prévienne le client. Sur une boutique réelle, la commande reste telle quelle : elle n'est ni marquée expédiée, ni modifiée, et vos clients ne reçoivent rien. L'action de création d'étiquette et la génération groupée le rappellent dans un bandeau avant chaque génération.

Le mode test est illimité, sur tous les plans : les étiquettes d'exemple ne comptent pas dans le quota de votre plan, voir [Plans et quotas](/docs/compte/plans-et-quotas).

Si vos identifiants sont enregistrés et vérifiés, myColis demande quand même à Colissimo de contrôler les données de chaque envoi, sans créer d'étiquette. Vous voyez ainsi les erreurs qu'un envoi réel produirait, par exemple une adresse refusée. Si ce contrôle ne peut pas avoir lieu, l'étiquette d'exemple est générée sans lui, avec le message « Mode test : Colissimo n'a pas pu vérifier les données pour le moment. Étiquette d'exemple générée sans cette vérification. »

## Où retrouver les étiquettes d'exemple

Dans la page **Envois**, les étiquettes d'exemple portent le badge **Démo**, ou le statut **Démo, non expédié** quand la commande n'a pas été marquée expédiée. Le filtre **Démo** les regroupe toutes. Elles s'impriment comme les autres, depuis Shopify ou depuis la page **Envois**.

La page **Bordereaux de dépôt** produit des bordereaux d'exemple à partir de ces étiquettes, avec le bandeau « Mode test : bordereaux d'exemple DEMO avec les étiquettes d'exemple, à ne pas remettre à La Poste. »

## Les points relais en mode test

Dans l'action myColis, la recherche de points relais ne contacte pas Colissimo. Elle renvoie cinq points fictifs situés autour de l'adresse recherchée, dont un en congés, que vous ne pouvez pas choisir. Ils portent le badge **Point fictif**. Sur une boutique réelle, le point choisi dans l'action sert seulement à l'étiquette d'exemple et n'est pas enregistré sur la commande, ce que l'action signale : « Mode test sur une boutique réelle : le point n'est pas enregistré sur la commande, il sert seulement à l'étiquette DEMO. »

Vos clients voient eux aussi des points fictifs, y compris sur une boutique réelle, quand trois conditions sont réunies : le mode test est activé, aucune clé API n'a été vérifiée par un test de connexion réussi, et au moins un tarif point relais est indiqué dans myColis. Les blocs que vous avez placés, au checkout, sur la page de remerciement ou dans le suivi de commande, leur proposent alors des points fictifs badgés **Point fictif**, sous le bandeau « Mode test : points relais fictifs » sauf sur une boutique de développement. Le point choisi par le client est enregistré sur la commande.

En mode test sans clé API vérifiée, les pages **Envois** et **Réglages** l'annoncent par un bandeau orange : « Mode test actif : vos clients voient des points relais fictifs. Avant de vendre, désactivez le mode test dans Réglages. » Son bouton **Voir le mode test** ouvre la section **Connexion Colissimo** des réglages.

Pour l'éviter pendant que vous préparez une boutique réelle, n'indiquez aucun tarif point relais avant de passer aux vraies étiquettes, voir [Tarifs point relais](/docs/points-relais/tarifs-point-relais). Vous pouvez aussi enregistrer votre clé API et obtenir **Connexion réussie** au test de connexion : vos clients voient alors les vrais points, même en mode test, et vos étiquettes restent des exemples.

Une commande restée avec un point fictif ne reçoit pas de vraie étiquette une fois le mode test désactivé. La création est refusée avec le message « Le point relais de la commande est un point fictif du mode test. Choisissez un vrai point relais dans l'action myColis. » Choisissez alors un vrai point dans l'action, voir [Choix dans l'admin](/docs/points-relais/choix-dans-l-admin).

## Pourquoi la configuration reste incomplète

En mode test, l'étape **Connecter et vérifier votre compte Colissimo** de la page **Envois** est facultative : elle porte le badge **Facultatif** et la mention « Facultatif en mode test : l'app fonctionne sans compte. », et le compteur des étapes obligatoires ne la compte pas. Elle ne se coche jamais en mode test, même avec des identifiants vérifiés, et la carte **Configuration de myColis** reste affichée tant que le mode test est actif. Vous pouvez la fermer avec sa croix, en haut à droite : elle ne revient plus ensuite, voir [Installer l'app](/docs/prise-en-main/installation).

Une fois la connexion vérifiée, l'étape porte aussi le badge **Connexion vérifiée** et la carte précise : « Mode test actif : étiquettes d'exemple seulement, aucun colis n'est expédié. Désactivez le mode test pour terminer cette étape. » Son bouton **Désactiver le mode test** ouvre la section **Connexion Colissimo** des réglages, où se trouve l'interrupteur **Mode test**.

## Passer aux vraies étiquettes

1. Configurez un expéditeur, puis enregistrez votre n° client et votre clé API ou votre mot de passe, voir [Connecter votre contrat Colissimo](/docs/prise-en-main/connexion-colissimo).
2. Désactivez l'interrupteur **Mode test**.
3. Sélectionnez **Tester la connexion** et attendez **Connexion réussie**.

Le message « Mode test désactivé : les prochaines étiquettes seront réelles » confirme le changement. Dès lors, chaque étiquette est créée chez Colissimo sur votre contrat, et compte dans le quota de votre plan myColis.

Sur une boutique réelle, une commande qui n'avait reçu qu'une étiquette d'exemple n'a pas été marquée expédiée : elle peut recevoir sa vraie étiquette, et l'étiquette d'exemple est alors remplacée, avec la mention « Étiquette d'exemple remplacée par une étiquette réelle après la désactivation du mode test. » Un point relais fictif resté sur une commande est refusé à la génération : « Le point relais de la commande est un point fictif du mode test. Choisissez un vrai point relais dans l'action myColis. »
